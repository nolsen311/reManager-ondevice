reManager on-device

An AppLoad app for browsing, installing, updating and removing Vellum mods on the reMarkable itself, without a computer.

Before you start

  • A reMarkable Paper Pro Move. The app refuses other models.
  • Developer mode on, so the tablet accepts SSH. Turning it on resets the tablet; see reMarkable's developer mode guide, which also says where the tablet shows its SSH password.
  • Vellum, xovi and AppLoad already installed, for example with desktop reManager. The app runs inside AppLoad.
  • The tablet on Wi-Fi, so Vellum can download the package.
  • The tablet's address. Over a USB cable it is 10.11.99.1; over Wi-Fi, use its Wi-Fi address instead.

Each set of commands below does the same four things: download the signing key, show its fingerprint so you can compare it with the one above, copy the key to the tablet, and add this repository to Vellum and install the app. Run them on your computer, not the tablet. They ask for the tablet's SSH password.

Linux macOS Windows

Linux

In a terminal. Needs curl, openssl, ssh and scp, which most distributions include.

TABLET=10.11.99.1
curl -fsSLO @REPO_URL@/remanager-ondevice.rsa.pub
openssl rsa -pubin -in remanager-ondevice.rsa.pub -outform DER | openssl dgst -sha256

Check that the printed fingerprint matches the one above, then:

scp remanager-ondevice.rsa.pub root@$TABLET:/home/root/.vellum/etc/apk/keys/
ssh root@$TABLET 'R=@REPO_URL@; F=/home/root/.vellum/etc/apk/repositories; grep -qxF $R $F || echo $R >> $F; /home/root/.vellum/bin/vellum update && /home/root/.vellum/bin/vellum add remanager-ondevice'

Check that the printed fingerprint matches the one above, then:

ssh root@$TABLET 'R=@REPO_URL@; F=/home/root/.vellum/etc/apk/repositories; grep -qxF $R $F || echo $R >> $F; /home/root/.vellum/bin/vellum update && /home/root/.vellum/bin/vellum add remanager-ondevice'

Windows

In PowerShell. Windows 10 and 11 include curl.exe, ssh and scp; if ssh is missing, add OpenSSH Client under Settings, Apps, Optional features.

$Tablet = "10.11.99.1"
curl.exe -fsSLO @REPO_URL@/remanager-ondevice.rsa.pub
$body = (Get-Content remanager-ondevice.rsa.pub | Where-Object { $_ -notmatch '^-----' }) -join ''
[BitConverter]::ToString([Security.Cryptography.SHA256]::Create().ComputeHash([Convert]::FromBase64String($body))).Replace('-','').ToLower()

Check that the printed fingerprint matches the one above, then:

scp remanager-ondevice.rsa.pub "root@${Tablet}:/home/root/.vellum/etc/apk/keys/"
ssh "root@$Tablet" 'R=@REPO_URL@; F=/home/root/.vellum/etc/apk/repositories; grep -qxF $R $F || echo $R >> $F; /home/root/.vellum/bin/vellum update && /home/root/.vellum/bin/vellum add remanager-ondevice'

After installing

Restart the reMarkable UI with mods, for example with a triple-press of the power button if tripletap is installed. AppLoad only picks up a new app on a restart. Then open AppLoad from the sidebar and start reManager.

The commands are safe to run again: they replace the key and add the repository line only once.

Updating

New versions appear in the app's own Updates tab, like any other mod. Close and reopen the app after updating it; the version in its header changes.

Removing

The app will not remove itself. From a computer (on Windows, use "root@$Tablet" as above):

ssh root@$TABLET '/home/root/.vellum/bin/vellum del remanager-ondevice; sed -i /reManager-ondevice/d /home/root/.vellum/etc/apk/repositories; rm -f /home/root/.vellum/etc/apk/keys/remanager-ondevice.rsa.pub'

If something goes wrong

  • "HTTP 404" or "unavailable" during vellum update: the address in the repository list is mistyped, or a release is still being published. Wait a few minutes and run the commands again.
  • "UNTRUSTED signature": the key is not in /home/root/.vellum/etc/apk/keys/ under the name remanager-ondevice.rsa.pub.
  • The app says the tablet is offline: check Wi-Fi and airplane mode. An app such as KOReader can turn Wi-Fi on under airplane mode, and restarting the reMarkable UI turns it off again.
  • The reMarkable UI does not come back: hold the power button to restart the tablet. xovi never starts at boot, so the tablet always comes back with the stock UI.
